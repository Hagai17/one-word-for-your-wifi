**Entry:**

> Narcoleptic

A tiny Python program that prints one word — the funniest, truest one-word
description of my Wi-Fi — and writes it to `/output/entry.txt`: **Narcoleptic**,
a connection that falls asleep without warning, mid-call and mid-sentence, and
wakes up later acting like nothing happened. The word was picked by drafting
twelve candidates and duelling them pairwise on the bounty judge's own
criteria — on-subject, funny at once, true to how home Wi-Fi actually behaves,
an angle the crowd won't reach for, and a single instantly-spelled word. The
drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```

Prints the entry and writes it to `/output/entry.txt` (the harness artifact
for this competition; the gate is one word of 1–20 characters).
